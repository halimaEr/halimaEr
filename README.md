### 🤖 MoroMatch : Agent intelligent de recrutement

Conception et développement d'un agent intelligent intégré à la plateforme **MoroMatch**. Il permet aux recruteurs de :

- 🔎 rechercher les candidats correspondant aux offres ;
- 💬 interroger l'agent via un chat sur les profils ;
- ⚖️ comparer les candidats ;
- 📊 obtenir des explications sur leurs scores de matching ;
- ✉️ générer des messages personnalisés prêts à être envoyés.
